## Course Description

This repository holds my laboratory work for CPE 010. The course covers the core data abstractions, data structures, and algorithms used to write efficient programs. I design algorithms for each data structure and use them to solve engineering-related problems in **C++**.

## Course Outcomes

1. Apply fundamental data structures and techniques to solve engineering-related problems through algorithm design.
2. Design efficient algorithms and analyze their complexity.
3. Build efficient algorithms based on selected data structures using good programming style in **C++**.

## Topics

**Prelim**
- Data structures and algorithm analysis (ADTs, space and time complexity)
- Arrays and linked lists (singly, doubly, circular)
- Stacks (array and linked list implementations)

**Midterm**
- Queues (array and linked list implementations)
- Searching (linear search, binary search, hashing)
- Basic sorting algorithms

**Final**
- Trees (binary search trees, AVL trees, traversals)
- Graphs (adjacency matrix and list, **BFS**, **DFS**)
- Algorithm analysis and time complexity classes
